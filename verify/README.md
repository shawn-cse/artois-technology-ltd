## Standard Employee Record Fields

The verification card uses an executive, universal schema that works identically for all corporate personnel (Directors, Management, Engineers, Project Managers, and Interns):

1. **Employee Name:** Full legal employee name
2. **Position / Role:** Title, role designation
3. **Verification ID:** Unique corporate ID (e.g., `ATL-IVR-XXXX`)
4. **Employee Status:** Pill with state (`Active • Ongoing`, `Completed • Term Fulfilled`, `Did Not Join • Offer Declined`)
5. **Joining / Offer Date:** Primary date
6. **Department / Team:** Division (e.g., `Software Engineering`, `Web Development & Engineering`)
7. **Employment Type:** Status classification (e.g., `Internship • Active`, `Full-Time`, etc.)
8. **Issuing Organisation:** `Artois Technology Limited`
