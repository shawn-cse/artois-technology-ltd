WHAT YOU WILL BUILD & MASTER

Key Technical Responsibilities

Gain structured hands-on experience across four core pillars of modern software engineering under senior guidance.

Client-Side Architecture

Frontend & Responsive UI Engineering

Build responsive, accessible, and fast web user interfaces that translate designs into seamless user experiences across modern desktop and mobile browsers.

  • Develop reusable, modular UI components using HTML5, modern CSS3, JavaScript (ES6+), and React / Next.js
  • Translate Figma/UI specifications into pixel-clean, accessible, and cross-browser compatible layouts
  • Implement client-side state management, responsive navigation flows, and interactive user inputs
  • Optimize frontend assets, loading speeds, and Core Web Vitals performance indicators
Server-Side Systems

Backend Architecture & RESTful APIs

Design and maintain server-side business logic, handle API requests, and integrate backend services that reliably power frontend applications.

  • Develop, test, and document scalable RESTful APIs and server endpoints using Node.js, Express, or Python
  • Implement input validation, authentication checks (JWT/session tokens), and centralized error handling
  • Connect server logic with external third-party webhooks, mailers, and cloud service integrations
  • Ensure backend stability, latency monitoring, and secure payload handling
Data Modeling & Queries

Database Engineering & Data Integrity

Structure relational and document schemas, formulate efficient queries, and ensure data remains consistent, secured, and properly indexed.

  • Work with relational and document databases including PostgreSQL and MongoDB
  • Write clean SQL queries, design schema migrations, and apply foreign-key relational constraints
  • Utilize modern ORM/ODM layers (such as Prisma or Mongoose) for safe, type-checked data queries
  • Understand database indexing, connection pooling, and baseline query performance optimization
Professional Workflows

Code Quality, Testing & Git Collaboration

Adopt the collaborative engineering standards that professional teams use to build reliable, long-lasting software together.

  • Write clean, maintainable, and self-documenting code following DRY and SOLID principles
  • Diagnose, debug, and resolve real-world software defects, test edge cases, and perform unit checks
  • Collaborate daily with Git and GitHub: feature branching, clean commit messages, and pull request reviews
  • Participate in Agile/Scrum sprint planning, daily standup check-ins, and architectural retrospectives
WHO WE ARE LOOKING FOR

Requirements & Candidate Profile

We value genuine curiosity, foundational computer science reasoning, and eagerness to learn over previous job titles.

Academic & Technical Foundations

  • Enrolled student or recent graduate in CSE, CS, SWE, IT, EEE, or a related computing field
  • Working grasp of Data Structures & Algorithms, Object-Oriented Programming (OOP), and software engineering basics
  • Basic coding proficiency in at least one modern language: JavaScript, TypeScript, Python, Java, or C/C++
  • Familiarity with core web building blocks (HTML5, CSS3, DOM) and basic Git/GitHub version control
  • Understanding of basic database operations (Tables, CRUD operations, SQL queries, or document stores)
Bonus Foundations (Not Mandatory): Prior exploration of React, Node.js, Next.js, or personal hobby repositories on GitHub is an advantage, but not a strict prerequisite.

Mindset & Professional Qualities

  • Curiosity & Problem Solving: Enthusiasm to research solutions, read technical documentation, and debug step-by-step
  • Coachability & Feedback: Openness to receiving constructive guidance in code reviews to steadily improve your code quality
  • Clear Communication: Proactive communication about blockers, sprint progress, and task statuses during daily standups
  • Team Collaboration: Readiness to work respectfully in a collaborative engineering culture that emphasizes mutual support
  • Commitment: Ability to allocate consistent weekly hours across the hybrid schedule throughout the 4–6 month duration
No Prior Job Experience Required We evaluate your analytical reasoning, dedication, and programming fundamentals over corporate work history. University projects, coursework, and personal repositories are welcome proof of your skills.
